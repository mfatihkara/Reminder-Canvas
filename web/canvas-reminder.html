Never miss a due date again.

CanvasAlert reads your Canvas iCal feed and texts you automatically — 3 days before, the day of, and 3 hours before every deadline.

How it works

1

Get your iCal URL

Grab your Canvas Calendar Feed link — no API token needed.

2

Add your Gmail

Use a Gmail account + App Password to send texts via email-to-SMS gateway.

3

Configure & run

Paste your generated .env file and run the Python script.

4

Get reminded

Sit back — texts arrive automatically before every assignment is due.

When you'll get texts

⏰ 3 days before due

Early heads-up so you can plan ahead.

📅 Day of due date

Reminder on the morning it's due.

🚨 3 hours before

Last-chance alert so nothing slips through.
